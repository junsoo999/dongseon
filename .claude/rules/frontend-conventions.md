# Frontend conventions

## Stack

Vite 8, React 19, TypeScript 7, TanStack Query, React Router, Tailwind CSS 4, `@vis.gl/react-google-maps` (M1), Vitest + Testing Library. Lint with oxlint, format with Prettier (`.prettierrc.json`: no semicolons, single quotes, width 100).

## Mobile first

The household uses the app on phones, mostly during the trip. Design at 390px first: map on top with
the list below, filters in a bottom sheet, tables as row lists, touch targets ≥ 44px, a five-tab bottom bar
under `md` (홈 / 장소 / 일정 / 오늘 / 더보기; 숙소, 항공, 준비, 설정 live under 더보기). The 오늘 tab is the
default during the trip. "내 위치" only appears in a secure context (https/localhost).

## Structure

```text
frontend/src/
├── pages/          # one component per route (Home, Places, Stays, Flights, Itinerary, Today, Prep, Settings, More)
├── components/     # reusable UI pieces
├── api/
│   ├── schema.d.ts # GENERATED by `make gen-types` — never edit by hand
│   ├── client.ts   # fetch wrapper + type aliases from schema.d.ts
│   └── hooks.ts    # TanStack Query hooks (one per endpoint)
├── lib/            # pure helpers (formatting, math) with colocated tests
└── router.tsx      # route table
```

## API access

- Components never call `fetch` directly; they use hooks from `api/hooks.ts`.
- Response types come from `api/schema.d.ts` (`components['schemas'][...]`). Do not hand-write duplicate interfaces.
- After changing a backend schema, run `make gen-types` and commit the result.
- Requests go to relative `/api/...`; the Vite dev server proxies them to `127.0.0.1:8101` (`DONGSEON_API_PORT`).

## Environment

- Vite reads `VITE_*` variables from the repo-root `.env` (`envDir: '..'`). Only public browser keys (`VITE_GOOGLE_MAPS_JS_KEY`, `VITE_GOOGLE_MAP_ID`) may use the `VITE_` prefix.

## UI text and formatting

- All UI text is **Korean**.
- Money: `formatMoney(amount, currency)` from `lib/format.ts`, shown next to the KRW conversion with the FX date.
- Durations: `formatMinutes()` → `"1시간 35분"`. Approximate travel times carry "근사"; representative-departure
  transit results carry "대표 시각 기준".
- Opening hours always show their source and check date; AI research shows "AI 조사, 출처, 확인 필요".
- Everything AI-generated carries "AI 제안".
- Google content shown without a Google map follows the attribution rules in `docs/google-terms.md`.

## Styling

- Tailwind utility classes; avoid custom CSS unless necessary (`index.css` holds globals only).

## Tests

- Colocate `*.test.ts(x)`. Wrap components using queries in a fresh `QueryClient` with `retry: false`.
- Mock network with `vi.stubGlobal('fetch', ...)`.
